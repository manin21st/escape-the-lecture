## 5. 픽셀 폰트 (스펙 #2611 지정)

```typescript
// Google Fonts CDN (index.html에 link 태그)
const FONTS = {
  heading: "'Press Start 2P'",  // 타이틀, 큰 배너
  body: "'VT323'",              // 대사, 일반 텍스트
  alt: "'Pixelify Sans'",       // 대안 (VT323 대신)
};

// HUD 폰트 사이즈
const FONT_SIZES = {
  title: '28px',
  hud: '14px',      // Press Start 2P 14px (HUD)
  dialog: '16px',   // VT323 16px (대사)
  small: '10px',    // Press Start 2P 10px (소)
};
```

**원칙 (스펙 #2611)**:
- 시스템 폰트, sans-serif, 모던 폰트 **절대 금지**
- `Gowun Dodum` (v1) 제거 — 레트로 픽셀 폰트만 사용
- 한국어 호환: VT323은 한글 지원 제한 → **Galmuri9 (무료 픽셀 한글 폰트)** 병행

### 한국어 픽셀 폰트 추가

| 폰트 | 라이선스 | 특징 |
|---|---|---|
| Galmuri9 | OFL | 한국어 픽셀 폰트, 9×9 bit |
| Galmuri11 | OFL | 한국어 픽셀 폰트, 11px |
| **Neo 둥근모고딕** | OFL | 둥근 고딕 픽셀 한글, HUD/대사용 (2026-05-30 채택) |

## 7. TextureManager 전략

```typescript
// PreloadScene에서 1회 등록
generateAllTextures(scene: Phaser.Scene): void {
  const g = scene.make.graphics({ add: false });

  // 타일 (런타임)
  generateTileTextures(g, scene);

  // 캐릭터 (런타임 or 에셋 파일)
  if (USE_ASSET_PACK) {
    // Sprout Lands / LPC 파일 로드 (Phaser loader)
    scene.textures.addSpriteSheet('player', playerPng, { frameWidth: 32, frameHeight: 32 });
  } else {
    // fallback: 런타임 생성
    generateCharTextures(g, scene);
  }

  g.destroy();
}

// 환경변수로 제어
const USE_ASSET_PACK = import.meta.env.VITE_USE_ASSETS === 'true';
```
