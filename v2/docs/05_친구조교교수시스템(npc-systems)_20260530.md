# 친구·조교·교수 시스템

## 1. 교수 (Professor) 시스템

### 1.1 핵심 원칙

> **스펙 #2611**: 교수는 연단에 고정. 절대 순찰하지 않음.  
> 교수의 역할은 LECTURE/WATCH 타이머와 대사/표정 변화.

### 1.2 AI 상태머신

```
lecture ──(lectureTime경과)──► watch
   ▲                              │
   │      ◄──(watchTime경과)──────┤
   │                              │
   │                   (WATCH 중 플레이어 이동 감지)
   │                              │
   │                          suspicion ← 4교시+ / SNITCH 이벤트
   │                              │
   │              ┌───────────────┤
   │              │               │
   │        (멈추면)         (계속 이동)
   │              │               │
   └──────────────┘            caught → 게임오버
```

### 1.3 대사 시스템 (한국어, 스펙 결정사항)

### 1.4 말풍선 스타일 (레트로 RPG)

```
┌─────────────────────────┐
│ 다음 슬라이드로 넘어갈게요 │  ← 픽셀 테두리, sharp corner
└──────────┬──────────────┘
           ▼ (픽셀 삼각형 꼬리)
      [교수 스프라이트]
```

- 폰트: VT323 (16px) — 레트로 스타일
- 배경: 0xfff8e0 (양피지), 테두리: 0x4a2c1a (갈색 3px)
- 자동 소멸: 3초

## 2. TA (Teaching Assistant) 시스템

### 2.1 시야 콘 판정 로직

```typescript
checkPlayerInCone(player: Player): 'outside' | 'suspicious' | 'detected' {
  const dx = player.x - this.x;
  const dy = player.y - this.y;
  const dist = Math.sqrt(dx * dx + dy * dy);

  // 거리 체크
  const rangeInPx = this.visionRange * TILE;
  if (dist > rangeInPx) return 'outside';

  // 각도 체크
  const angle = Math.atan2(dy, dx);
  let diff = Math.abs(angle - this.facingAngle);
  // 각도 정규화 (0~π)
  while (diff > Math.PI) diff = Math.abs(diff - 2 * Math.PI);
  const halfCone = (this.visionAngle / 2) * DEG_TO_RAD;

  if (diff > halfCone) return 'outside';

  // 장애물(DESK, WALL) 차단 체크
  if (this.hasObstacleBetween(this.tileX, this.tileY, player.tileX, player.tileY)) {
    return 'outside';
  }

  // 거리 비율로 suspicious/detected 구분
  if (dist < rangeInPx * 0.5) return 'detected';    // 절반 거리 이내 = 즉시 발각
  return 'suspicious';                                // 외곽 = 주황 경고
}
```

### 2.2 TA 상태 전이

```
normal ──(플레이어 suspicious zone)──► suspicious
   │                                        │
   │◄──(플레이어 벗어남)────────────────────┘
   │
   │         (detected 진입)
   │              │
           detected → 게임오버
```

`suspicious` 상태에서 플레이어가 1.5초 내에 빠져나오면 `normal`로 복귀.

### 2.3 TA 순찰 경로 업데이트

```typescript
// 경로 이동 (목표 타일 도달 시 다음 waypoint)
updatePatrol(dt: number): void {
  const target = this.patrolPath[this.patrolIdx];
  const tx = target.x * TILE + TILE / 2;
  const ty = target.y * TILE + TILE / 2;
  const dist = Phaser.Math.Distance.Between(this.x, this.y, tx, ty);

  if (dist < 4) {
    this.patrolIdx = (this.patrolIdx + 1) % this.patrolPath.length;
    this.snapToTile();
    this.updateFacingAngle();   // 다음 경로 방향으로 시야 콘 회전
  } else {
    const angle = Phaser.Math.Angle.Between(this.x, this.y, tx, ty);
    this.x += Math.cos(angle) * this.patrolSpeed * dt;
    this.y += Math.sin(angle) * this.patrolSpeed * dt;
    this.facingAngle = angle;   // 이동 방향 = 시야 방향
  }

  this.drawVisionCone();
}
```

### 2.4 Good Friend의 TA 유도 효과

```typescript
// GoodFriend가 B타입 행동 시 — 가장 가까운 TA를 친구 위치로 유도
distractNearestTA(friendTile: TilePoint, scene: GameScene): void {
  const nearestTA = scene.entityManager.getNearestTA(friendTile);
  if (!nearestTA) return;

  // TA 순찰 경로에 친구 위치 임시 삽입
  nearestTA.insertTemporaryWaypoint(friendTile, duration: 4);
  // 4초 후 원래 순찰 경로 복귀
}
```

## 3. 친구 (Friend) 시스템

### 3.1 3종류 친구 결정 흐름

```
[플레이어가 친구 클릭]
         │
    ─────────────
    │           │           │
  GOOD       SLEEPING    SNITCH
    │           │           │
교수/TA     "zzzz..."    "교수님!"
질문 유도   (효과 없음)   위험 증가
```

### 3.2 GoodFriend 행동 선택

클릭 시 랜덤으로 A 또는 B:

**A — 교수 질문** (60%):
```
1. 친구 말풍선: "교수님, 질문 있습니다!"
2. 교수 -> lecture 모드 강제 (watchTime 일시 중단)
3. 교수 lectureTime += 3~5초 (MOVE 기회 확장)
4. 교수 말풍선: "음, 좋은 질문이에요..."
```

**B — TA 질문** (40%, TA가 있는 경우에만):
```
1. 친구 말풍선: "조교님, 과제 어디에 내요?"
2. 가장 가까운 TA가 친구 위치로 이동
3. 해당 통로 4초간 개방
4. TA 말풍선: "아, 거기 내시면..."
```

### 3.3 SnitchFriend 이벤트

```typescript
triggerSnitchEvent(scene: GameScene): void {
  // 1. 말풍선
  this.showBubble("교수님! 누가 나가려 해요!", style: { borderColor: 0xc44545 });

  // 2. 교수 반응
  scene.professor.triggerSuspicion();

  // 3. WATCH 시간 연장
  scene.phaseManager.extendWatchTime(1.5);  // 1.5배

  // 4. 4교시+ 빨간 플래시
  if (scene.period >= 4) {
    scene.cameras.main.flash(400, 200, 40, 40, false);
  }

  // 5. 친구 사용 횟수 소모 (고자질도 카운트 차감)
  scene.hud.decreaseFriendCount();
}
```

## 4. Phase Manager (통합)

```typescript
type Phase = 'lecture' | 'watch' | 'suspicion' | 'snitch_suspicion';

class PhaseManager {
  currentPhase: Phase = 'lecture';
  timer: number = 0;
  phaseTotal: number;

  // 특수 override
  forcedLecture: boolean = false;
  forcedLectureTimer: number = 0;
  watchMultiplier: number = 1.0;  // SNITCH 시 1.5

  enterLecture(initial?: boolean): void;
  enterWatch(isSuspicion?: boolean): void;
  triggerSnitchEvent(): void;
  extendWatchTime(multiplier: number): void;
  forceLectureMode(seconds: number): void;  // GoodFriend A타입

  update(dt: number): void;
}
```
